# Bundled fonts

These files are bundled so `GoogleFonts.config.allowRuntimeFetching = false`
works offline in release builds.

Families:

- Plus Jakarta Sans (OFL)
- PT Serif (OFL)
- Fira Code (OFL)

Downloaded from [Fontsource](https://fontsource.org/) CDNs / Google Fonts
projects. Keep license terms of the original SIL Open Font License.
