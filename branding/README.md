# Branding

- `AppIcon.icon` — Apple Icon Composer source (Liquid Glass). Used by iOS as `ios/Runner/AppIcon.icon`.
- `app_icon_1024.png` — Flattened 1024×1024 export (orange gradient + logo) for Android/web/legacy assets.

Edit the `.icon` in Icon Composer, then re-copy to `ios/Runner/AppIcon.icon` and regenerate platform PNGs from the SVG/PNG assets if needed.
